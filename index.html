→ 오른쪽 아래 Generate new token 클릭
→ Generate new token (classic) 선택
→ Note에 아무 이름 입력 (예: vault)
→ repo 체크박스 클릭 ✅
→ 맨 아래 Generate token 클릭
→ 나온 토큰 복사해두기! (다시 못 봐요)
